统计什么

启用后，浏览器会向 Umami Cloud 发送页面路径、标题、来源路径及浏览器、设备和语言等基础信息。本集成移除页面与来源地址中的查询参数和片段，不启用会话录像、错误采集、个人身份关联或自定义事件。

Umami 在处理请求时可能使用 IP 地址推导粗略位置和匿名会话标识。标准统计记录不把 IP 作为单独字段保存，不代表服务商的基础设施或安全日志完全不处理 IP。详见 Umami 隐私政策和 统计口径。

数字怎么理解

浏览量表示采集到的页面浏览；访客数是服务按匿名标识规则估算的去重数，不是经过身份核验的真人数量。网络失败、脚本拦截、共享网络、设备变化和自动化访问都会影响结果。当前使用 Umami Cloud Hobby 免费套餐，数据保留期限为 6 个月，不承诺永久累计。

原 Visitor Badge 属于徽章加载次数，不能代表独立读者，也不能转换为新统计的历史访客数。正式分析与旧徽章采用不同口径。

排除本人的访问

你可以在当前浏览器选择不参与本站 Umami 统计。设置仅保存在本机本站的 localStorage 中，不是跨设备的账号设置。每个浏览器需要分别设置，清除站点数据后需要重新设置。

启用 JavaScript 后可查看和修改当前浏览器的统计偏好。

退出从设置成功后生效，不会追溯删除此前统计。取消排除不会在本页立即发送事件，之后浏览其他页面时才可能恢复。本站也尊重浏览器提供的 Do Not Track 和 Global Privacy Control 信号，并排除本地预览与已标识的自动化验收；这些措施不构成精确的人机识别。
