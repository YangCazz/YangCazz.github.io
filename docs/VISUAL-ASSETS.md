# 视觉资产管理

## 目录与事实边界

- 统一 UI 图标：[使用说明](ICON_SYSTEM.md)；`_data/icons.json` 为唯一源，`assets/icons/catalog.html` 为可视目录；通过 `icon.html` include 或本地 sprite 使用。功能图标不使用 emoji、字符箭头或远程图标服务；品牌标志不冒充原创重绘。
- 展示页：`showcase.html`、`_sass/_showcase.scss`；使用正常文档滚动，不依赖脚本显示正文。
- 展示插图：`assets/images/showcase/`；论文/研究配图：`assets/images/research/20261030/`。
- 清单：`_data/visual_assets/*.json`，每批独立 JSON 数组，避免多人维护一个大文件。
- 当前清单覆盖本轮新增/复用的资产，**不是全站历史图片权属审计结论**。历史文章中表达语义的 emoji 不等于 UI 图标；历史品牌/论文截图需保留来源，不盲目替换。

实际截图、原创结构图、生成插图应在可见图注中区分。不得把概念图当作产品截图、把生成图片当作论文原图或真实实验结果。医学项目不得在缺少可核查依据时展示精度、临床效果、注册证、SOTA 等指标。展示页以站内实际应用与工程记录为基础，不推断仓库当前部署状态。

## 最小清单字段

| 字段 | 约定 |
| --- | --- |
| `id` | 全局唯一、稳定的小写标识 |
| `path` | 本仓库绝对站点路径，以 `/assets/` 开头；不可外链热链 |
| `kind` | `source-screenshot` / `original-diagram` / `generated-illustration` / `original-icon` 等明确类别 |
| `title`, `alt` | 用途与替代文字；装饰性图标的 alt 可以为空，组件需 aria-hidden |
| `source_url` | 原始出处；原创资产可用本站来源或 null，不伪造来源 |
| `verified_at` | ISO 日期，表示本轮核查日期，不代表来源发表日期 |
| `rights` | 来源/授权/原创性质及限制，不把公开可读当作可任意复用 |
| `used_by` | 仓库内真实引用文件数组 |
| `source_title`, `source_date` | 来源标题、发表日期；信息不足用 null |
| `modifications` | 裁切、压缩、重绘、抽象等变更 |
| `sha256` | 建议记录最终本地文件的 SHA-256 |
| `status`, `archive_reason` | 被否定或停用的素材保留 `status: archived` 与原因，`used_by: []`；不得继续作为正文/封面使用 |
| `generation` | 生成图必填：实际工具、prompt、生成日期；未知后端模型不猜测 |

新增内容先查是否已有合适图片，避免同一通用封面反复承担无关主题。截图应来自当前可运行界面；旧版教程明确标记，不能用新版截图冒充旧界面。图中所示研究流程必须核对论文原文；文字纠错与图片变化一起记录。

## 科研图统一范式

后续科研生成配图遵循 [科研图视觉规范](SCIENTIFIC-FIGURE-STYLE.md)，以用户明确认可的 iCaRL v3 为唯一视觉参照。锚点文件 SHA-256 由回归测试锁定；未经用户同意不要修改锚点。规范只统一表达方式，不允许为适配模板而改变科学关系。

## 使用与验收

1. 保留原始来源/证据，给文件取稳定语义名，不覆盖旧批次。
2. 优先 SVG 处理图标和精确结构图；生成栅格图用于确实受益于插画表达的主题。
3. 精确结构图不宜作为标题背景裁切；文章可设置 `cover_image: false` 保留 `image` 元数据及正文完整配图，而不叠成背景。图片写入宽高与有意义的 alt，首屏按需优先加载，其余懒加载；保持纵横比。
4. 运行 `python3 _scripts/check-visual-assets.py` 与 `npm test`，随后 Jekyll 构建、站点/元数据检查和全文章浏览器回归。
5. 查看桌面与手机真实截图，检查字体层级、对比、留白、裁切、横向溢出、键盘焦点及无脚本可读性。

## 预览、升级与回退

本轮仅本地待审阅，不自动推送或上线。发布前保存当前提交与所有本地修改，按 README 锁定依赖构建；不要在用户主机自动执行命令。确认通过后再按既有 GitHub Actions 流程发布，不能据此推断 Pages 的仓库设置已切换。

回退可恢复本轮之前的 `showcase.html` 与 `_sass/_showcase.scss`，图标/文章资产按相应变更一并回退；若之后已经独立提交，用 `git revert <本轮提交>` 形成可审计回退，不强推或删除数据。静态站无数据库迁移。
